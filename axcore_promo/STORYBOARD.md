## 0. 공통 시스템 (프롬프트 작성법 → AXCORE 적용)

| 작성법 항목 | 원문 지시 | AXCORE 적용 |
|---|---|---|
| PALETTE | 잉크·종이·회색 + 강조색 1개 | 잉크 = 딥 네이비 `#050B1C`·`#0A2C73`, 종이 = 웜화이트 `#F5F4EF`·`#FBFAF6`, 회색 = 스틸 `#5E6064`·`#C9CED5`, 강조 = 밝은 장면 AXCORE 블루 `#0054FE` / 어두운 장면 시안 `#3CD3FF`. UI 카드 면에는 순백 `#FFFFFF`도 사용(원문과 다른 점) |
| HERO SUBJECT | 한 화면에 히어로 1개, 강조색은 히어로만 | 각 컷의 "히어로" 항목 참조. 강조 방식은 셀렉티브 리컬러(테두리·글로우·배지)로 통일 |
| SUBJECT PREPARATION | 스크립트 기반 배경 제거, B/W 변환 | 배경 제거 대신 스크립트 추적: `track.py`가 표면 호모그래피·광류 점·MediaPipe 손 21점 추출 → 그래픽이 영상에 고정, 손은 마스크로 그래픽 위에 재합성 |
| EDGE TREATMENT | 컷 가장자리 선택 + 긴 접지 그림자 | 찢긴 종이 대신 ① 글래스 카드(백드롭 블러·헤어라인 보더·상단 스펙큘러) ② 여백 없는 사각 프린트(영상 타일) 두 가지. 모두 부드러운 접지 그림자 |
| PEOPLE | 가로 띠 분할, 어긋난 등장 | 얼굴 비노출(뒷모습·손). 띠 분할은 미적용(코퍼레이트 톤 유지), 손은 실제 영상 동작으로 표현 |
| VARIATION | chaos 0~1 + seed, 재현 가능 | `--seed`(기본 20261007), `--chaos`(기본 0.35)가 타일 위치, 창 회전, 모듈 부유, 모자이크 분할, 등장 지터를 모두 구동. 같은 값이면 같은 프레임 |
| TYPOGRAPHY | 굵은 세리프 + 얇은 설명줄 | 고딕 Pretendard, 자간 0%. 굵기 대비(Bold·SemiBold 제목 ↔ Medium·Light 설명) |
| BACKGROUND | 저대비 신문 조각 | 밝은 장면은 44px 도트 그리드, 어두운 장면은 네이비 스테이지 클립과 플로어 그리드 |
| MOTION | 2.5D 드리프트, 비트 푸시인, expo+오버슛, 스태거, 히어로 마지막, 블러 분리 | 모든 컷이 멈추지 않는 드리프트(클립 자체 움직임 + 절반 강도 디지털 무브), 비트 푸시인은 히어로에 착지, `settle()` = ease-out expo + 4.5% 오버슛 후 안착, 히어로는 마지막 등장. 초점 블러(디포커스)와 속도 블러(휩 팬 수평 고스트)는 분리 |
| TEXTURE & FINISH | 하프톤·제록스, 가장자리 색수차, 비네트, 전환 시 라이트 리크 | 하프톤·제록스는 미적용(코퍼레이트 톤). 섀도·미드톤에만 걸리는 그레인 0.024, 가장자리 색수차 1.0013, 밝은 화면에서 자동 완화되는 비네트, 라이트 리크는 전환에만 |
| FRAME CADENCE | 등장 순간만 스텝, 나머지 풀프레임 | `enter()`의 앞 40%만 12fps 스텝, 이후 24fps 보간. 카메라·초점·다이어그램 선은 항상 24fps |
