# AXCORE 홍보영상 v4 — 씬별 컷 설계서

120.0초 · 1920×1080 · 24fps · 나레이션 0.8초 프리롤. 시간은 모두 최종 영상 기준(초).
소스 흐름: 나노바나나 Pro 플레이트(씬1은 고객 이미지) → Kling 3.0 Pro 클립(플레이트가 첫 프레임) → 정규화·추적 → Python(skia) 합성.

## v4 변경 요약
| 요청 | 반영 |
|---|---|
| 씬1을 첨부 이미지로 영상화(단순 확대·축소 X) | 고객 이미지(`assets/ref/scene1_city.webp`)를 시작 프레임으로 Kling 8초 항공 무브(전진 + 우측 아크, 실제 시차) 생성 → `25_city8` |
| 전체 톤 밝게 | 플레이트 그레이드 밝기 +4~10%, 비네트 0.22→0.15, 전 프레임 감마 리프트(0.93) |
| 시안 리본 → 라인 파티클 | `line_flow()`: 머리카락처럼 가는 선 다발이 곡선을 따라 흐르며 서로 꼬이고(리본 트위스트) 밝은 헤드·긴 꼬리·스파크. 추적된 건물 실루엣 뒤로 지나가며 건물을 휘감음(씬1 타워, 씬2 고층 빌딩, 연결 도시 씬, 엔딩 AX) |
| 전환 효과음 제거 | 우시·틱 등 전환 SFX 전부 삭제(음악만) |
| 전환은 매치컷 | `lines`: 라인 파티클 파도가 지나가며 그 뒤로 다음 컷이 실려 들어옴 / `match`: 구도·형태가 이어지는 하드 매치컷(유리 타워→유리 파사드, 진단 카드→AXpoint 창, 원목 책상→원목 책상, AI 검색창→질문, 생산 라인→로봇 셀). 와이프·줌·블록·휩 삭제 |
| 개인·기업: 태블릿 손 정면 클로즈업 + 그 위 글래스 그래픽 | 새 플레이트·클립 2종(`30_tab_personal`, `31_tab_ent`), MediaPipe로 탭하는 손 추적. 탭할 때마다 기능이 화면에서 떠올라 위의 글래스 패널로 들어감, 손은 그래픽 위로 재합성 |
| 기업 UI는 M-AI-Works 시트 참고 | Ontology AI 바 · 8대 핵심 기능 8열(경영관리·제품설계·생산관리·장비관리·품질검사·재고·물류·영업관리·고객지원 + 하위 기능) · AI Agent 열 · 주요 정보(BI) 행 |
| 진단 구간 텍스트 한글화 | 기획·생산·물류·영업·품질·사무·IT 시스템·재무, 배지 "디지털 전환"/"AI 전환", 흐름 진단·분석·설계·실행 |
| AXpoint 동작·구성 | 실제 데모 흐름을 핵심만: 파일 업로드 → 자료 확인 + 디지털화 수준(L3) → 업무 흐름 분석(AI 적용 지점) → 개선 과제 우선순위. 밝은 글래스 창 하나, 스톡 위 밑줄 삭제 |
| "하나로 연결" 씬 로고 제거 | 중앙은 로고 대신 "하나로 연결된 업무 환경" 허브 카드 |
| Gmail·Slack·Notion 실제 아이콘 | 공식 SVG를 래스터화한 `assets/icons/*.png` 사용 |
| OCR 종이·책상 | 새 플레이트: 새 흰 종이의 한글 작업일보 + 밝은 원목 책상(`33_ocr`). 인식 위치는 사각형 대신 행 아래 밑줄 |
| 온톨로지 한글 + 아이소메트릭 구조 | 유리 플랫폼 위 원판 노드(설비·자재·공정·제품·사람·업무), 점선 관계 + 한글 라벨(투입·가동·생산·출하·작업·관리·사용), 상단 시스템 데이터 스트림(ERP·MES·문서·센서·메일), 앞면에 업무 흐름 시작→끝(수주→생산 계획→자재 구매→생산→품질 검사→출하) 펄스 + AI 코어 "업무 흐름과 맥락을 이해" |
| 온톨로지 타이틀 로고 잘림 | 로고 리빌 클립 버그 수정(오른쪽 14% 잘리던 문제) |
| "더 빠른 판단" 태블릿 빈 화면 | 화면 사각형을 프레임마다 검출·추적해 대시보드(가동률·불량률·납기, AI 판단 카드)를 원근에 맞춰 합성, 휘도 키로 엄지는 화면 위에 유지 |
| 마지막 3문장: 컷 X, SK AX식 | 네이비 점이 꼭짓점을 찍고 선이 이어져 도형이 되고 영상이 채워짐 → 카메라가 물러나면 모든 도형이 큰 "AX"의 획 → 솔리드 네이비 AX → 각 획이 AXCORE 로고의 획("/", 다이아몬드, "X")으로 모핑 → CORE·블루 E 등장 |
| 쉬는 구간 + 정확히 2:00 | 강조 문장 앞 11곳에 무음 삽입(원본 녹음의 무음 지점에서 분할), 합계 +10.5초 → 120.0초 |
| 웅장한 배경음악 | D단조(Dm–B♭–F–C, 90BPM) 시네마틱 스코어, 로고에서 D장조로 해결. 현악 앙상블·옥타브 바이올린·저음 브라스 스웰·첼로 오스티나토·타이코·벨 모티프, 룸 리버브. 사이드체인으로 나레이션 중 약 9dB 덕킹(목소리가 음악보다 약 12dB 위) |
