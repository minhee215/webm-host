# HNKENG 메인 히어로 영상 — 시안 B (스토리보드)

스토리보드 "INTELLIGENCE IN MOTION — 산업을 이해하는 기술, 미래를 연결하는 지능"을 실사풍 18초 루프 영상으로 만든 시안입니다.
시안 A(무드보드 기반)는 `../hnkeng-hero/`에 그대로 있습니다. 인물은 뒷모습으로만 등장하고, 텍스트·로고는 HTML로 분리했습니다.

스토리 흐름: 산업 현장 → 자동제어 → 공정 자동화 → 데이터 운영 → 통합 스마트팩토리

## 장면 구성 (18.0초, 24fps, 하드 컷)

| 구간 | 장면 | 화면 | 카메라 연출 | 전달 메시지 |
|---|---|---|---|---|
| 0–3초 | 01 산업의 시작 | 화학·소재 플랜트 전경, 증기·구름 | 느린 수평 이동(슬라이드) | 다양한 산업을 이해하는 엔지니어링 전문성 |
| 3–7초 | 02 정밀한 자동제어 | PLC 제어반, 상태 LED 점멸 | 부드러운 줌인 | 핵심 기술 PLC·HMI·DCS 제어 역량 |
| 7–11초 | 03 움직이는 자동화 | 로봇 팔이 부품을 컨베이어에 배치 | 측면 이동(트래킹) | 생산성과 품질을 높이는 공정 자동화 |
| 11–15초 | 04 데이터와 지능의 연결 | HMI·SCADA 공정도·차트, 운전원 뒷모습 | 느린 수평 이동 | 데이터로 연결되는 스마트한 운영 |
| 15–18초 | 05 연결된 미래 | 스마트팩토리 전경, 로봇 셀 가동 | 완만한 줌아웃·크레인업 | 산업 전반을 연결하는 통합 솔루션 |

## 폴더 구성

| 경로 | 설명 |
|---|---|
| `stills/01~05.jpg` | 장면별 실사풍 스틸 (GPT Image 2.6) |
| `clips/01~05.mp4` | 스틸을 첫 프레임으로 생성한 5초 클립 (Kling 3.0 Standard, 720p 24fps, 무음) |
| `build/edit.py` | 편집·색보정·인코딩 (`SHOTS` 표에서 구간·카메라 이동 조정) |
| `build/stabilize.py` | 서브픽셀 손떨림 보정 + 등속 디지털 카메라 이동 |
| `dist/` | 결과물 (hero-video.mp4, -web.mp4/.webm, -mobile.mp4, 포스터) |
| `component/hero-section.html`, `index.html` | 반응형 히어로 컴포넌트와 미리보기 |

## 렌더링

```bash
pip install pillow numpy
python3 build/edit.py                              # 1280x720 (기본)
python3 build/edit.py --width 854 --height 480     # 480p 샘플
```
